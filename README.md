# Multi-Agentic AI Automated Workflow
Results of a multi-agent orchestration test for bulding an hydrological model without supervision

## Background

Experiment done to test the capabilities of multi-agent orchestration for building a hydrological model without supervision. The goal is to see if multiple AI agents can collaborate to create a functional model of streamflow in the Leaf River, from watershed characterization to model calibration and validation, without human intervention. The agents are designed to communicate and share information, allowing them to work together to achieve the desired outcome.

Activity in the context of **HWRS 696F FALL 2026 - The Future of Geo-Scientific Modeling (Agentic AI)** class

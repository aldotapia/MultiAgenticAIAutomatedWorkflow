def fetch(url: str, name: str, timeout: int = 120) -> Path | None:
    """Download `url` once into a temp cache. Returns None if the network is unavailable."""
    p = CACHE / name
    if p.exists() and p.stat().st_size > 0:
        return p
    try:
        with urllib.request.urlopen(url, timeout=timeout) as r:
            p.write_bytes(r.read())
        return p if p.stat().st_size > 0 else None
    except Exception as e:                                   # pragma: no cover
        print(f"[warn] could not fetch {name}: {e}")
        return None

def rdb(path: Path) -> pd.DataFrame:
    """Read a USGS RDB file (comment lines '#', second row = format codes)."""
    import io

    return pd.read_csv(io.StringIO(txt), sep="\t", dtype=str).iloc[1:].reset_index(drop=True)
ImportantEvaluation-period firewall

Everything computed from data/raw/LeafRiverDaily.txt in this report uses only the calibration window (1951-10-01..1988-09-30, metric window 1952-10-01..1988-09-30), loaded through src/common/data.py. No observed streamflow inside the evaluation window (1948-10-01..1951-09-30) was used for any number, prior, figure or recommendation. 1 Summary

  • Gauge (VERIFIED). USGS 02472000 “LEAF RIVER NR COLLINS, MS”, 31.70694 °N, −89.40694 °W (NAD83), Covington County, HUC-8 03170004 “Upper Leaf”; gauge datum 196.77 ft (59.98 m) NAVD88; record continuous since 1938-09-12 (U.S. Geological Survey 2026).
  • Area (VERIFIED, three independent sources). NWIS 743 mi² = 1924.4 km²; NHDPlus/NLDI polygon 1926.9 km²; GAGES-II 1927.1 km². The effective area embedded in the modelling data file is 1949.1 km² (§2.3) — the classic literature value “1944 km²” is right to 0.3 %.
  • Data-file identity (VERIFIED). Daily Q in LeafRiverDaily.txt reproduces USGS daily discharge at 02472000 with r = 1.000000 and RMSE 0.0010 mm/d over the whole calibration window when converted with A = 1949.1 km². This independently confirms the record start 1948-10-01 (ISSUE-001 resolution) — see §2.3.
  • Climate (VERIFIED). Humid subtropical (Köppen Cfa); PRISM 1971–2000 basin mean P = 1521 mm/yr, T = 17.7 °C; data-file calibration means P = 1427, PET = 1059, Q = 494 mm/yr ⇒ runoff ratio 0.35, aridity index PET/P = 0.74 (Falcone 2011).
  • Snow is irrelevant (VERIFIED). Snow = 0.8 % of precipitation (McCabe–Wolock grid via GAGES-II); NOAA 1991–2020 normals inside the basin: 0.9 in (23 mm) of snowfall per year ≈ 0.15 % of annual P as SWE (NOAA National Centers for Environmental Information 2021). No snow module is needed.
  • Seasonality is ET-driven, not P-driven (VERIFIED). Monthly P varies only 81–152 mm (seasonality index 0.119) while monthly Q varies 11–87 mm; PET swings 31→141 mm/month. ⇒ soil-moisture accounting with an ET-limited store is the single most important process.
  • Slow, well-damped system (VERIFIED, calibration data only). P→Q cross-correlation peaks at lag 3 d (r = 0.48); master recession constant k = 0.915 d⁻¹ (residence time ≈ 11 d); Kirpich t_c ≈ 1.4 d. ⇒ two or more parallel linear stores plus a short (1–3 d) routing lag.
  • Substantial but not dominant baseflow (VERIFIED). Wolock BFI grid 29.9 %; Lyne–Hollick filter on the calibration record 31–41 %; flow never reaches zero (min 0.069 mm/d). ⇒ a slow groundwater store with a ~10–60 d time constant is required; a deep “unobserved loss” flux may help (GR4J-style exchange).
  • Essentially unregulated (VERIFIED). GAGES-II class “Ref” (least-disturbed), HCDN-2009 member, hydrologic-disturbance index 9; total dam storage in 1980 = 4.0 mm of basin-equivalent depth (0.8 % of annual runoff). MDEQ: the Pascagoula system is “the last unregulated major river system in the lower 48 states” (Mississippi Department of Environmental Quality 2026). ⇒ no reservoir routine, no withdrawal term.
  • Realistic performance target. Independent benchmarks at this gauge: NWM v2.1 KGE 0.72 / NSE 0.71; calibrated SAC-SMA NSE 0.796, HBV(cal.) 0.819, FUSE 0.78, VIC 0.72, mHM 0.70, regional LSTM 0.84–0.86 (Towler et al. 2023; Kratzert et al. 2019). A well-calibrated conceptual model should reach NSE ≈ 0.80–0.87 here.

Conclusions for a02 (all VERIFIED):

  1. Q is mm/day, not m³/s. The conversion actually used by the NWS when the file was built is Q_mm = Q_m3s · 86.4 / 1949.1 km² (= Q_cfs · 0.0283168 · 86.4 / 1949.1 = Q_cfs · 0.00125523). Using the NWIS area 1924.4 km² would give a +1.3 % bias, using the literature 1944 km² a +0.26 % bias.
  2. The record starts 1948-10-01: with that alignment, daily r = 1.000000 against USGS; shifting the calendar by ±265 or ±365 days destroys the correspondence (water-year means: r drops from 1.00000 to 0.35 / 0.11). This is independent confirmation of the ISSUE-001 resolution (periods.definition: dates).
  3. Q at this gauge has no missing days in 1951-10-01…1988-09-30, and GAGES-II reports only 0.6 % estimated values over the whole record (Falcone 2011) — so data quality is not a limiting factor.

Interpretation. This is a low-relief, elongated, well-drained Coastal-Plain basin: 130 m of total relief spread over a 73 km long, 109 km-of-main-stem catchment, mean slope 2.5 %. The mean channel gradient is ≈ 1.2 m/km. Consequences for modelling:

  • Gravity-driven fast runoff is weak; storage, not topography, controls the hydrograph.
  • The high topographic wetness index (12.69) and the shallow seasonal water table (1.12 m, §5) mean variable source areas / saturation excess near the valley bottoms are physically plausible — a “probability-distributed store” (HYMOD/PDM/GR4J-style) is the natural abstraction.

def lyne_hollick(x, a=0.925, passes=3):
    y = x.copy()
    for p in range(passes):
        if p % 2: y = y[::-1]
        f = np.zeros_like(y); f[0] = y[0]
        for i in range(1, len(y)):
            f[i] = a*f[i-1] + (1+a)/2*(y[i]-y[i-1])
        b = np.minimum(y, y - np.maximum(f, 0))
        if p % 2: b = b[::-1]; y = y[::-1]
        y = b
    return y

Short version for a03 — a defensible five-model portfolio

  1. A probability-distributed soil store + parallel fast/slow linear reservoirs (HYMOD/PDM family) — matches the variable-source-area evidence; the documented weak spot on this record is the missing groundwater exchange (Wang and Gupta 2024).
  2. GR4J — 4 parameters, includes the groundwater-exchange term that Wang and Gupta (2024) found decisive here, and already scores NSE ≈ 0.68 (median annual KGE) on this exact data set.
  3. SAC-SMA (no Snow-17) — the model this data set was built for; the two lower-zone free-water stores directly encode the 11 d / 549 d two-timescale baseflow evidence; benchmark NSE 0.796 at this gauge.
  4. HBV-style with two-outlet lower box + triangular UH — the calibrated-HBV benchmark is the best conceptual model at this gauge (NSE 0.819).
  5. An LSTM / hybrid — the regional-LSTM benchmark at this gauge is NSE 0.84–0.86, but a single-basin LSTM trained on 36 years has far fewer samples; expect it to be competitive, not automatically best. WarningWarm-up length

The evaluation protocol allows only 92 days of warm-up (1948-10-01…1948-12-31). With a slow store of τ ≈ 30–100 d that is 1–3 e-folding times — not enough to forget a bad initial condition. Recommendation to a03/a10/a16: initialise the slow store analytically from the first observed low flows of the warm-up period only (that is inside the warm-up, not the metric window — but note that even that touches evaluation rows, so it must be done by a16 or by a state-independent rule), or better, choose initial states as calibrated parameters fitted on the calibration period and reuse them.
